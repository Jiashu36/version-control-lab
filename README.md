## What the Program Does

The program asks for the user's name and a temperature in Celsius. It converts the temperature to Fahrenheit using `fahrenheit = celsius * 9 / 5 + 32`, then displays a personalized message with the result rounded to one decimal place.

The temperature can be a whole number, a decimal, or a negative number. If the input is not a number, the program displays an error message. Run the cell again to try another input.

## How to Run

1. Download `temperature_converter.ipynb` and open it in Jupyter Notebook or upload it to SCI JupyterHub.
2. Use a Python 3 kernel and run the code cell with **Shift + Enter**.
3. Enter your name when prompted.
4. Enter a temperature in Celsius, using only a number (for example, `25`).

No additional Python packages are needed.
